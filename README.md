# Medical App — мониторинг онкомаркеров щитовидной железы

Система мониторинга лабораторных показателей и онкомаркеров пациентов до и после операции на щитовидной железе. Включает экспертную систему оценки риска послеоперационного рецидива на основе клинических правил.

## Состав проекта

| Модуль | Описание |
|---|---|
| `src/` | Бэкенд: Spring Boot 3 (Java 17), PostgreSQL, Liquibase, JWT |
| `mobile/` | Мобильный клиент v1 (Flutter) |
| `mobile_v2/` | Мобильный клиент v2 (Flutter) — переработанный UI для ролей «пациент» и «врач» |
| `scripts/` | Python-скрипты валидации экспертной системы на ретроспективном датасете |

## Возможности

- **Роли**: администратор, врач, пациент (JWT-аутентификация, разграничение доступа)
- **Загрузка анализов** из Excel (Apache POI) с автоматическим разбором показателей
- **Нормы показателей**: справочник с CRUD для администратора
- **Экспертная система**: клинические правила (условия над фактами пациента), журнал срабатываний, управление правилами через API
- **Аналитика пациента**: скоринг риска, динамика показателей до/после операции
- **Портал пациента**: просмотр собственных результатов и заключений
- **Чат врач–пациент**: треды и сообщения
- **PDF-отчёты** по результатам анализов (PDFBox)
- **Swagger UI**: документация API на `/swagger-ui.html`

## Быстрый старт (Docker)

```bash
cp .env.example .env   # при необходимости отредактировать значения
docker compose up --build
```

Приложение поднимется на `http://localhost:8080`, PostgreSQL — на порту `5433` (чтобы не конфликтовать с локальным PostgreSQL на 5432).

## Локальный запуск (без Docker)

1. Поднять PostgreSQL и создать базу `medical`.
2. Запустить бэкенд с dev-профилем:

```bash
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

Параметры подключения переопределяются переменными окружения `SPRING_DATASOURCE_URL`, `SPRING_DATASOURCE_USERNAME`, `SPRING_DATASOURCE_PASSWORD`.

3. (Опционально) Создать демо-аккаунты:

```bash
mvn exec:java
```

## Переменные окружения

Полный список — в [.env.example](.env.example). Ключевые:

| Переменная | Назначение |
|---|---|
| `JWT_SECRET` | Секрет подписи JWT (минимум 32 символа) |
| `ADMIN_SECRET` | Секрет для регистрации администратора |
| `POSTGRES_PASSWORD` | Пароль БД |
| `CORS_ALLOWED_ORIGINS` | Разрешённые origin для CORS |
| `SPRING_PROFILES_ACTIVE` | Профиль: `dev` / `prod` |

## Валидация экспертной системы

Скрипт прогоняет правила экспертной системы по ретроспективному датасету (300 анонимизированных пациентов после операции на ЩЖ) и считает метрики качества:

```bash
cd scripts
pip install -r requirements.txt
python validate_expert_system.py --data dataspeed.xlsx --rules rules_export.json
```

Результаты (матрица ошибок, частота срабатывания правил, распределение тяжести по рецидиву) сохраняются в `scripts/out/`.

## Тесты

```bash
mvn test
```

Юнит-тесты покрывают JWT, валидацию пользователей, скоринг аналитики и вычислитель условий экспертной системы.
